# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and patient, assume good intent, welcome newcomers, and keep
discussions about the work. Harassment, insults and personal attacks are not tolerated.

Report unacceptable behaviour by opening a private security advisory on the repository, or by
contacting the maintainer through their GitHub profile. Reports are handled confidentially.
