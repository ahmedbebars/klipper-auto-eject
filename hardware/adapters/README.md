# Toolhead adapters

Mounts for toolheads the universal mount doesn't fit well. Each adapter replaces
`mount_screws` / `mount_strap` and must keep the same interface for the arm:

- two M3 holes **10 mm apart** (x = ±5 mm), centred on the plate
- M3 nut traps on the toolhead side
- a flat front face at least 20 mm wide for the arm's upright

Add a folder per toolhead with the source (OpenSCAD, STEP or a CAD link), the STL, a photo of
it mounted, and a short README listing the screws used.
